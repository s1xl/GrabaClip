# Código de conducta / Code of conduct

GrabaClip es un proyecto abierto a cualquier persona. Para que siga siendo un buen lugar:

- Trata a los demás con respeto, sin importar su experiencia, origen, identidad o forma de pensar.
- Critica ideas y código, nunca a las personas. Las sugerencias se agradecen.
- No se aceptan acosos, insultos, amenazas ni contenido sexual o violento.
- No publiques datos privados de otras personas.

Si ves algo que no cumple estas normas, avisa al responsable del proyecto ([@s1xl](https://github.com/s1xl)) abriendo un *issue* o por mensaje privado. Se revisará cada caso y se podrá quitar el contenido o bloquear a quien lo publicó.

---

GrabaClip is open to everyone. Be respectful, criticize ideas and code (not people), no harassment, insults, threats, sexual or violent content, and do not publish other people's private data. Report problems to the maintainer ([@s1xl](https://github.com/s1xl)) via an issue or private message; the maintainer may remove content or block users who break these rules.
